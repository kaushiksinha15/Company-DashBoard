# 🏢 Company Registration Dashboard

A modern React-based dashboard for company registration, user authentication, and profile management. The application provides an intuitive interface for users to register, log in, manage their profiles, and access dashboard functionalities.

## ✨ Features

- 🔐 User Authentication (Login & Registration)
- 👤 Profile Management
- 📊 Interactive Dashboard
- 🎨 Responsive UI
- ⚡ Built with React + Vite
- 🧭 Navigation System
- 🌙 Modern Material UI Components

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- Material UI

### Development Tools
- Git & GitHub
- npm

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/<username>/Company-DashBoard.git
cd Company-DashBoard
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Application will be available at:

```bash
http://localhost:5173
```
